## How to use this repo

- Each file is self-contained: a short explanation followed by the commands you'd actually run.
- Commands are shown in code blocks so you can copy-paste directly into a terminal.
- Where relevant, files include a "common gotchas" section based on real troubleshooting scenarios.

## Who this is for

Anyone starting out in IT Ops / sysadmin work who wants a no-fluff command reference, or anyone prepping for day-to-day Linux server administration tasks.
